## Getting Started

### Prerequisites

- Node.js 22+
- npm

### Clone

```bash
git clone https://github.com/bytebysatyam/satyam-shukla-portfolio.git
cd satyam-shukla-portfolio
```

### Install dependencies

```bash
npm ci
```

### Start development

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Testing

The project includes automated checks for core contact-flow behavior and build verification.

```bash
npm test
npm run build
```
